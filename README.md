### Selected work / Trabajo seleccionado

**[Diversidad y salud mental en México](https://github.com/beraun/diversidad-salud-mental-mx-estudio)**  
A reproducible data analysis using Mexico’s ENDISEG 2021 survey (INEGI), with methodology, aggregate results, code and an executive presentation. The findings describe associations, not causation.

*Análisis reproducible de la ENDISEG 2021 (INEGI), con metodología, resultados agregados, código y presentación ejecutiva. Los hallazgos describen asociaciones, no causalidad.*

Other experiments and projects are being developed privately. I share public work when its documentation and scope are ready.
